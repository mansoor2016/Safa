# Adhan Audio Files

Audio files for the Islamic call to prayer (Adhan), used in prayer notifications.

| File | Reciter | Description |
|------|---------|-------------|
| `abdulbasit_abdusamad.caf` | Abdul Basit Abdul Samad | Egyptian master reciter known as "The Golden Throat". Rich, deeply emotive Maqam Bayati melody in the classic Egyptian style. |
| `adham_al_sharqawe.caf` | Adham Al Sharqawe | Egyptian muezzin with a powerful, resonant voice. Ornate melodic style with extended vocal runs in the Egyptian tradition. |
| `ahmad_al_trablsi.caf` | Ahmad Al Trablsi | Levantine reciter with a clear, measured delivery. Warm tonal quality with a traditional Shami (Syrian/Lebanese) melodic feel. |
| `ahmed_el_kourdi.caf` | Ahmed El Kourdi | Muezzin with a gentle, contemplative tone. Subtle Maqam Hijaz inflections creating a serene and reverent atmosphere. |
| `hamza_al_majale.caf` | Hamza Al Majale | Jordanian reciter with a bright, soaring voice. Melodically rich adhan with confident, uplifting phrasing. |
| `ismail_al_sheikh.caf` | Ismail Al Sheikh | Muezzin with a soft, intimate vocal quality. Restrained and meditative delivery, suited for quiet reflection. |
| `mishary_alafasy_fajr.caf` | Mishary Rashid Alafasy | Kuwaiti Imam of Masjid Al-Kabir. Fajr-specific adhan with the additional "As-salatu khayrun min an-nawm" phrase. Gentle pre-dawn tone. |
| `mishary_alafasy.caf` | Mishary Rashid Alafasy | Kuwait's most renowned reciter and Imam. Signature Kuwaiti-style adhan with a polished, melodious delivery and precise tajweed. |
| `muhammad_al_damradash.caf` | Muhammad Al Damradash | Egyptian muezzin with a strong, commanding voice. Traditional Cairo-style call with bold Maqam Rast progression. |
| `muhammad_ramadan_saad_makkah.caf` | Muhammad Ramadan Saad | Makkah Haram-style adhan with the distinctive echo and grandeur of the Holy Mosque. Majestic, slow-paced and deeply reverential. |
| `rabeh_ibn_darah.caf` | Rabeh Ibn Darah Al Jazairi | Algerian muezzin performing the Adhan of Algeria. North African melodic style with Andalusian-influenced ornamentation. |

## Format
- Codec: AAC in CAF container (PCM for abdulbasit due to low-quality source)
- Tracked via Git LFS
- Full-length recordings for in-app playback
- For notification sounds (max 30s), trimmed versions would need to be created

## Sources
Recordings sourced from public Islamic audio archives. All adhans are traditional religious calls to prayer.
